# Günlük bütçe

Düzensiz geliri olanlar (öğrenciler, part-time çalışanlar) için tek bir soruya cevap veren uygulama: **bugün ne kadar harcayabilirim?**

**Aç:** https://zeplonn.github.io/gunluk-butce/

- **iPhone:** Safari'de aç → Paylaş → **Ana Ekrana Ekle**
- **Android:** Chrome'da aç → ⋮ menü → **Ana ekrana ekle / Uygulamayı yükle**

Bilgilerin sadece kendi telefonunda kalır; bu sitede hiçbir kullanıcı verisi tutulmaz. Telefon değiştirirken Ayarlar → **Yedek** bölümünü kullan.

> Not (iPhone): Ana ekrana eklenen uygulamanın bilgileri Safari sekmesinden ayrı tutulur. Bilgilerini ana ekrandaki uygulamaya gir.
